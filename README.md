# DuskMeld

DuskMeld enables scalable, distributed system management through adaptive predictive-modeling auto-scaling, utilizing a centralized Controller and decentralized Agent architecture.

DuskMeld is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/DuskMeld.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

DuskMeld is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
